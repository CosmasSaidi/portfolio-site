# Portfolio Site

Professional cybersecurity portfolio website for presenting skills, practical learning progress, and documentation repositories.

**Live:** https://cosmassaidi.github.io/portfolio-site/

## Purpose

- Present a polished personal brand for junior cybersecurity opportunities
- Highlight concept-first learning and practical lab progression
- Centralize links to writeups, notes, and core repositories

## Content Focus

- Kali/Linux setup and workflow maturity
- Web security fundamentals (SQLi, XSS, input handling risks)
- Reconnaissance and enumeration methodology
- Burp Suite, Nmap, and Gobuster tool usage context
- Structured roadmap for continued growth

## Stack

- HTML5
- CSS3 (responsive, modern UI)
- Lightweight JavaScript for UX polish

## Notes

- This site emphasizes concepts, skills, writeups, and notes.
- No direct platform solutions are published.
