Hello, World!

I'm Cosmas Saidi, a passionate cybersecurity learner focused on understanding systems at their deepest level. My journey in security started with curiosity about how things work—and more importantly, how they can fail.

I believe that to truly defend systems, you must understand how they can be attacked. That's why I focus on offensive security skills like reverse engineering and binary exploitation, while always maintaining an ethical approach.

Current Focus

I'm currently deepening my skills through pwn.college, an incredible platform that provides hands-on security challenges. My areas of focus include:

  • Linux internals and system security
  • Reverse engineering with Ghidra and GDB
  • Binary exploitation and memory corruption
  • Security automation with Python
  • Understanding modern exploit mitigations

Philosophy

I approach security with a learning mindset. Every challenge is an opportunity to understand something new. I document my learning through detailed writeups that focus on methodology and concepts—helping others learn while reinforcing my own understanding.

I believe in ethical hacking and responsible disclosure. Security knowledge should be used to build better defenses, not to cause harm.

Goals

  • Master binary exploitation techniques
  • Contribute to open-source security tools
  • Work as a security researcher or penetration tester
  • Help others learn through clear documentation
