VulnVault

VulnVault Lab Documentation

Local vulnerable web app lab used for controlled web security practice and writeup validation.

Lab Purpose and Scope

  • Run a controlled local target for repeatable web security testing.
  • Practice recon, parameter testing, and input-handling analysis safely.
  • Keep testing inside localhost scope for ethical and operational control.
  • Use findings to improve structured documentation and reporting quality.

Workflow Used

  • Baseline app behavior before testing endpoints.
  • Enumerate routes and parameters with manual + tool-assisted checks.
  • Validate observations through repeat requests and response comparison.
  • Document evidence, risk context, and defensive actions in markdown writeups.

Tools in the Lab Cycle

  • Burp Suite for request/response interception and replay.
  • Gobuster for route and content discovery.
  • Browser DevTools and terminal utilities for verification.
  • Git-based note tracking for reproducibility.

Documented Outcomes

  • Web enumeration and reconnaissance process notes.
  • XSS and SQL injection learning writeups with practical context.
  • File-upload and web-shell risk documentation.
  • Clear offensive-to-defensive interpretation in final notes.
