Linux Fundamentals

Linux powers most servers and security tools. Mastery of the command line is essential.

pwd          # Current directory
ls -la       # List with permissions
cat file.txt # View file
find / -name "*.conf"  # Find files
id           # Current user/groups

File Permissions

Permissions split into: owner, group, others. Octal: r=4, w=2, x=1

chmod 755 script.sh   # rwxr-xr-x
chmod 600 secret.txt  # rw------- (owner only)

Security: Misconfigured permissions = unauthorized access. Never use 777 in production.

Shell Scripting

+
bash sh awk sed grep

Script Basics

#!/bin/bash
echo "Hello"
VAR=$(command)    # Command substitution
chmod +x script.sh
./script.sh

Key Concepts

• Scripts need shebang (#!/bin/bash) to specify interpreter

• Command substitution: $(command) or backticks

• Variables: no $ when assigning, $ when reading

Security: Always validate input. Never run untrusted scripts with elevated privileges.

Environment & PATH

+
env export printenv which

Environment Variables

env                    # View all variables
echo $PATH             # View PATH
export MYVAR="value"   # Set variable
printenv               # Print environment

PATH Manipulation

export PATH=/my/dir:$PATH
which command          # Find command location

Security: PATH is searched left to right. If a privileged script calls commands without full paths, an attacker can hijack execution.

Security: Background processes can persist after logout. Be aware of orphaned processes.
